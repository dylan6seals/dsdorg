## Troubleshooting

**Server won't start?**
- Port 3000 might be in use
- Kill other Node processes

**Can't see changes?**
- Hard refresh: Ctrl+Shift+R
- Clear browser cache

**Upload failing?**
- Check file size (50MB limit)
- Ensure uploads/ directory exists

**Database locked?**
- Only one server instance at a time
- Restart server if needed
